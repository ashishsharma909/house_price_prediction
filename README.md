# House Price Prediction

This project predicts house prices using Linear Regression.

## Steps
- Load and clean housing dataset
- Feature selection
- Train/Test split
- Linear Regression model
- Evaluation using RMSE and R2
- Save model and make predictions

## Run
python train_model.py 
It will train the model
## Run
python predict_app.py 
It will tale input from user as per requirements to predict the house price
